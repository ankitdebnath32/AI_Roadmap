What changes and what does not

Temperature, top-k, and top-p alter decoding from existing logits. They do not add knowledge or change model parameters.

Attention weights determine one layer’s value mixture. They are not a complete explanation of the final answer.

KV cache speeds decode by reusing previous keys and values. It does not expand the trained context window or avoid prefill.

Fine-tuning changes weights. RAG changes runtime context. Prompting changes the current input.

Architecture and Transformer cheat sheets

LLM architecture cheat sheet

  • Text → tokenizer → token IDs
  • IDs → embeddings + position
  • N Transformer blocks refine residual stream
  • Attention mixes across visible tokens
  • FFN computes within each token
  • Final hidden state → vocabulary logits
  • Softmax and decoding choose next token
  • Append token, update KV cache, repeat

Transformer cheat sheet

  • Q: what this position seeks
  • K: what each position matches on
  • V: information each position contributes
  • Attention = softmax(QKᵀ/√dk + mask)V
  • Heads are parallel learned subspaces
  • Residuals preserve identity paths
  • Norm stabilizes feature scale
  • Block = attention update + FFN update
