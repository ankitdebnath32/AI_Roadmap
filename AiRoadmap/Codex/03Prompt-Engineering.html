Final Reference

Production prompt checklist
  • Prompt has owner, version, purpose, inputs, outputs, and model target.
  • Instructions and untrusted data are separated with clear labels and delimiters.
  • Output is schema-validated and failures have retry or fallback behavior.
  • Tools are least-privilege, authorized by code, logged, and confirmation-gated for writes.
  • RAG answers cite source IDs and abstain when evidence is missing.
  • Prompt has golden tests, adversarial tests, eval metrics, and rollback plan.
  • Telemetry tracks quality, latency, cost, parse failures, tool errors, and safety events.
Prompt engineering cheat sheet

Baseline: task + context + constraints + output format + examples + validation. Debug order: rendered prompt, boundaries, examples, context, schema, model settings, traces. Optimize: measure first, change one variable, compare by segment, roll out gradually.

Evaluation framework

Use offline datasets for correctness and regression, adversarial suites for injection and jailbreaks, schema checks for parseability, human rubrics for subjective quality, and online telemetry for real-world drift. Track quality together with latency, cost, and safety.
