Stable architecture vs current API

Design for concepts; isolate imports. Model adapters, messages, schemas, tools, state machines, checkpoints, idempotency, and observability are durable. Factory names, import paths, prebuilt nodes, integration packages, and stream modes can move. This workbook uses current LangChain v1 and LangGraph concepts verified against official documentation, while marking API examples as version-sensitive. Pin dependencies and verify migration notes before production upgrades.

Cheat sheets and workflow patterns

      
LangChain cheat sheet
  1. Model adapters normalize provider interaction.
  2. Messages preserve role and tool protocol.
  3. Templates render versioned prompts.
  4. Structured output validates shape, not truth.
  5. Retrievers own evidence selection.
  6. LCEL composes deterministic runnables.
  7. Tools are least-privilege RPC boundaries.
  8. create_agent supplies a configurable model-tool loop.

      
LangGraph cheat sheet
  1. State is schema plus reducers.
  2. Nodes return partial updates.
  3. Edges encode control flow.
  4. Loops need progress and limits.
  5. Checkpoints persist thread execution.
  6. Interrupts suspend and later resume.
  7. Side effects must be idempotent.
  8. Recovery belongs in graph topology.

      
Agent workflow patterns
  1. Router: classify then select one path.
  2. Tool loop: model ↔ authorized tools.
  3. Evaluator-optimizer: draft, critique, revise.
  4. Parallelization: independent workers plus reducer.
  5. Human approval: proposal, interrupt, revalidate, execute.
  6. Supervisor: typed worker routing plus task ledger.
  7. Fallback: primary path to deterministic degraded mode.
  8. Compensation: record and undo partial side effects.
