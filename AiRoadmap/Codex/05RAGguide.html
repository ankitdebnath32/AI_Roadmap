End-to-end Azure data flow
  1. Documents enter private Blob Storage with source metadata and an authoritative version.
  2. Events or scheduled reconciliation trigger queued Azure Functions that parse, chunk, enrich, and request embeddings.
  3. Functions push chunk text, vectors, tenant/ACL metadata, and source pointers into a versioned Azure AI Search index.
  4. The Spring Boot query API authenticates with Entra ID, derives security filters, embeds the query, and sends hybrid text/vector search.
  5. AI Search merges text and vector ranks with RRF, optionally applies semantic ranking, and returns authorized evidence.
  6. The API builds context and calls Azure OpenAI; it validates answer structure and citations before streaming/finalizing.
  7. Cosmos DB stores suitable session/feedback/job state; Application Insights links dependency timing, relevance telemetry, failures, tokens, and cost.
Spring Boot request sketch
AuthorizationScope scope = entitlements.resolve(authentication);
float[] queryVector = embeddings.embedQuery(request.question());
SearchRequest search = hybridQuery(request.question(), queryVector)
    .filter(scope.toODataFilter())
    .vectorK(50).top(8).semanticConfiguration("kb-semantic");
EvidenceContext context = contextBuilder.pack(aiSearch.search(search));
return groundedGenerator.stream(request.question(), context);

Final Reference & 21-Day Plan

RAG cheat sheet

  • Separate ingestion and query paths.
  • Chunk for answerable evidence, not uniformity.
  • Use hybrid retrieval for mixed query types.
  • Measure candidate recall before reranking.
  • Pack diverse evidence under a token budget.
  • Validate support and citation IDs.
  • Abstain when evidence is insufficient.

Failure taxonomy

  • Source absent or stale
  • Parse/chunk destroyed evidence
  • Filter removed authorized evidence
  • Retriever missed it
  • Reranker/context dropped it
  • Model misused it
  • Citation/validator failed

Metrics by stage

  • Ingestion: freshness and coverage
  • Retrieval: recall, hit rate, MRR
  • Ranking: NDCG and precision
  • Context: relevance and coverage
  • Answer: relevance and faithfulness
  • Production: p95/p99, cost, failures
  • Security: isolation and injection pass rate
